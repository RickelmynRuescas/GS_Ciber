# Memória Digital - Módulo de Cybersecurity (mock)
Global Solution 2026.2 · FIAP

## Forma mais simples
Abra a pasta inteira no VS Code, rode o script e puxe o arquivo `dashboard.html` para o navegador.

## Como rodar
Requer Python 3.9+ (sem dependências externas).

    python memoria_digital_security.py

Gera `eventos.json` e `dashboard.html`. Abra o `dashboard.html` no navegador (duplo clique) e clique em "Reproduzir atividade".
## Arquivos
- memoria_digital_security.py: PII + Taint Analysis + tradução via IA
- dashboard_template.html: modelo do painel
- dashboard.html: painel Risco Cidadão gerado
- eventos.json: eventos da execução
- saida_execucao.txt: saída do terminal
- video_dashboard.mp4: gravação do painel (adicionar)
